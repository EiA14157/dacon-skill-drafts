# 이미지 결함과 비전 모델 검증

1. 공식 지표·제출 구조·외부 가중치 규칙을 확인한다. 이미지 단위 단일/다중 레이블, 박스, 마스크, 정상 위주 데이터 중 무엇인지 실제 파일로 확인한다. 생산 로트, 원본 이미지 파생본, 제품, 카메라에 걸친 유사 샘플이 있으면 분할에 반영한다.
2. 크기 분포, 깨진 파일, 클래스별 수, 결함 위치·크기, 배경과 조명 차이를 표본으로 확인한다. 결함이 작으면 전체 리사이즈에서 손실될 수 있다는 가설을 세우고 고해상도 또는 타일을 통제 실험으로 비교한다. 타일과 원본의 분할을 함께 묶고 타일 예측은 원본 ID로 집계한다.
3. 이미지 단위 레이블이 있으면 가벼운 CNN을 기준으로 잡고, 규칙이 허용하면 사전학습 CNN을 먼저 파인튜닝한다. 충분한 데이터·예산이 있으면 다른 백본을 같은 분할에서 비교한다. 박스·마스크가 있으면 해당 출력에 맞는 검출·분할 기준 모델을 두고, 정상 위주 데이터에서는 특징 기반 이상 점수 접근을 검토한다.
4. 학습 초기에 한 배치와 검증·추론 경로를 실행한다. 증강은 실제 결함의 방향·색·질감을 보존하는지 시각적으로 확인한다. 클래스 가중치·샘플링, 증강, 입력 크기, 백본을 한 번에 한 요인씩 바꾼다. 확률 임계값이나 TTA는 대회 규칙을 확인하고 별도 검증에서 평가한다.
5. 공식 점수와 함께 클래스별 정밀도·재현율 및 해당하는 오류 표를 기록한다. 검출·분할이면 크기별 미검출과 오검출도 점검한다. 배경·카메라·로트별 실패 사례를 확인하고, 원인 가설 하나와 다음 검증 실험을 연결한다.
