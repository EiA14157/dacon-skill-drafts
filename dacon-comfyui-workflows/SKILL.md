# ComfyUI 이미지 생성 실험

1. 목표 이미지와 비교 기준을 정의하고 현재 ComfyUI 워크플로, 사용 가능한 체크포인트와 모델 계열, 노드 요구사항을 확인한다. SDXL 등 모델 계열과 LoRA·어댑터·텍스트 인코더·VAE의 호환성을 모델 설명과 실제 로드 결과로 확인한다.
2. 적정 해상도와 단일 시드로 체크포인트, 텍스트 인코딩, 잠재 공간, 샘플링, 디코드, 저장 경로를 한 번 실행한다. 오류가 나면 실패 노드와 모델 파일·형식·메모리 상태를 확인한다.
3. 프롬프트, 모델, LoRA 강도, 샘플러, 업스케일 단계 중 한 변수를 바꾸고 나머지 설정과 시드를 유지한다. 후보가 비슷하면 추가 시드로 일관성을 확인한다.
4. 출력 세트마다 워크플로 JSON, 모델 이름·버전, 전체 프롬프트, 시드·해상도·샘플링 설정을 기록하고 이미지 품질과 비용을 비교한다.

## 주제 출처

[DACON 랭커특강 목록](https://dacon.io/hackathon#videoSection)에서 최신순으로 표시된 42개 카드 중 9번. ComfyUI를 이용한 이미지 생성 입문. 공개 제목을 바탕으로 적용 절차를 작성했다.
