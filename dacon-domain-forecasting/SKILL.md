# 시계열·금융·의료 데이터 검증

1. 예측 단위, 예측 시점, 예측 기간, 레이블 관측 시점, 변수별 실제 입수 시점을 표로 적는다. 대회 규칙과 데이터 수집 구조를 먼저 확인한다.
2. 미래 예측은 실제 예측 기간과 맞춘 rolling 또는 expanding 검증을 구성한다. 레이블 창이 겹치거나 정보 공개에 지연이 있으면 필요한 간격을 반영한다. 환자·기관·고객·센서 반복 관측은 평가 환경에 맞춰 그룹과 시간을 분리한다.
3. 시계열은 마지막 값·계절 나이브 등 단순 기준을 먼저 측정하고 lag·rolling 피처 모델을 비교한다. 역사 자료 개정, 장 마감 이후 공개, 사후 의료 코드처럼 당시 없던 정보는 변수 입수 시점으로 점검한다.
4. 강우는 계절·지역·극단값, 전력은 휴일·계절·피크, 금융은 기간별 변동과 희소 사건, 의료는 기관·환자·희소 클래스별 표본 수와 오류를 확인한다. 진단이나 투자 판단 요청에는 해당 도메인의 별도 검증 요건을 적용한다.
5. 공식 지표와 기간·그룹별 점수, 표본 수, 가장 큰 실패 구간을 보고한다. 분할 정의와 누수 검증을 재실행할 수 있도록 기록하고 모델 선택 근거와 다음 실험을 제시한다.
