# LLM·RAG·AI 에이전트 평가

1. 생성·분류·문서검색·도구 실행 중 목표를 정의하고, 정답·근거·기대 동작을 포함한 고정 평가셋을 만든다. 답이 없는 질문, 유사 문서, 오래된 문서, 도구 실패를 포함한다.
2. 구조화된 프롬프트나 단순 검색으로 기준선을 실행한다. 문서 기반 과제는 청킹, 검색 방식, top-k, 재순위화 중 하나씩 바꾼다. 검색의 Recall@k와 답변 정확도·근거 일치율을 분리해 측정하고 오류를 검색 실패와 생성 실패로 구분한다.
3. 도구 호출이 필요한 사례에서는 도구 스키마, 허용 작업, 최대 반복, 타임아웃과 성공 조건을 정의한다. 외부 텍스트는 데이터로 취급하고, 쓰기 테스트는 테스트 데이터와 확인된 권한 범위에서 실행한다.
4. 대회 코드 개선에 사용하면 실행 가능한 제안과 변경점을 기록하고 기존 베이스라인과 같은 분할에서 점수를 재측정한다. 검증셋에 맞춘 프롬프트나 검색 설정은 별도 최종 평가셋에서 확인한다.
5. 결과표에 모델·설정·문서 스냅샷, 근거 품질, 과제 성공률, 토큰·지연·호출 수, 대표 실패와 다음 실험을 남긴다.
