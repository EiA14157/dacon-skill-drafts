# AI 앱·캡스톤 프로토타이핑

1. 핵심 사용자와 과제를 한 문장으로 정의하고, 입력에서 결과까지 관찰 가능한 완료 조건을 적는다. 기존 앱·의존성·데이터 저장소를 먼저 확인한다.
2. 화면, API, 저장소, 외부 도구 사이의 데이터 계약을 정한다. MVP에서 필요한 외부 기능이 있을 때 MCP 또는 기존 API의 도구 스키마, 실패 동작, 권한을 확인한다.
3. 더미 데이터로 사용자 흐름을 먼저 통과시킨 다음 실제 API와 DB를 연결한다. DB를 사용하는 경우 정상 저장, 조회, 누락 입력, 중복 요청, 외부 서비스 실패를 검증한다. 계정이 있는 앱은 사용자 간 데이터 접근 범위를 테스트한다.
4. 실행 명령과 필요한 설정 이름, 검증한 사용자 동선과 확인 결과를 기록한다. 환경 의존성으로 실행이 막히면 확인한 범위와 남은 단계를 적는다.

## 주제 출처

[DACON 랭커특강 목록](https://dacon.io/hackathon#videoSection)에서 최신순으로 표시된 42개 카드 중 4–6·18번. 바이브코딩 기초·아키텍처/MCP·DB 풀스택 실전, AI 캡스톤. 공개 제목을 바탕으로 적용 절차를 작성했다.
