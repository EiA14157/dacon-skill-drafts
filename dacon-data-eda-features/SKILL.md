# 데이터 EDA와 피처 엔지니어링

1. 데이터 사전, 키, 테이블 관계, 예측 시점과 실제 파일을 읽는다. 행 수, 유일 키, 조인 카디널리티, 결측, 중복·근접 중복, 레이블 분포와 깨진 데이터를 검사하고 검사 코드를 실행한다.
2. 학습·평가 데이터의 분포를 비교할 때 예측 시 사용 가능한 변수와 규칙을 확인한다. 정형은 범주·수치 분포와 그룹별 표본 수, 이미지는 형식·해상도·클래스별 대표 예시와 배치별 샘플 수, 시계열은 시간 간격과 누락 구간을 우선 확인한다.
3. 각 피처의 출처·이용 가능 시각·기대 효과를 적는다. 결측 대치, 스케일링, 인코딩, 재표집과 피처 선택은 폴드의 학습 부분에서 적합한다. 타깃 인코딩은 학습 내부 교차 적합을 적용하고 시간 집계는 예측 시점 이전 자료로 제한한다.
4. 원본 베이스라인과 피처 묶음을 하나씩 추가한 모델을 같은 분할·예산으로 실행한다. AutoML 사용 시 분할과 공식 점수를 동일하게 재현하고 탐색 시간과 최종 설정을 기록한다.
5. 의사결정에 영향을 준 그래프와 표에 표본 수, 단위, 기간, 결측 처리 기준을 표시한다. 최종 결과로 데이터 품질표, 피처 채택·보류 근거, 검증 점수 변화, 재현 경로를 제공한다.
